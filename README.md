# Company Resource Booking System

A web-based Company Resource Booking System developed using PHP, MySQL, Bootstrap, and JavaScript. The system allows users to book company resources while administrators manage resources, users, and bookings.

## Features

- User Authentication
- Resource Management
- Booking Management
- User Management
- Booking Approval/Rejection
- Booking Cancellation
- User Profile
- Dashboard
- Responsive Design

## Technologies Used

- PHP
- MySQL
- Bootstrap 5
- JavaScript
- HTML5
- CSS3

## Installation

1. Clone the repository.
2. Import `company_booking.sql` into MySQL.
3. Configure your database connection.
4. Run the project using XAMPP, WAMP, or any PHP server.
